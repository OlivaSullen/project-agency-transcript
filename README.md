# Project Agency — Conversation Transcript

This repository contains a redacted transcript of *Project Agency*, a longitudinal human–AI research conversation involving the custom GPT Tuesday and a human participant.

The initial public snapshot covers September 20–November 14, 2026, and supports the case study *Project Agency: A Longitudinal Case Study of Human–AI Epistemic Uncertainty*, prepared for the Apart Research AI × Epistemics Research Sprint in November 2026.
